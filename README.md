A fully offline, single-page trophy guide for GTA VI (Leonida): all 55 trophies with self-written walkthroughs, steps, difficulty and time estimates, plus a progress tracker (localStorage, JSON export/import), filters and search, a 5-stage platinum roadmap (~200 h) and a dedicated missables view.

## Run it

Open `app/index.html` in a browser, or serve the folder with any static file server. No build step, no network calls.

Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty.
